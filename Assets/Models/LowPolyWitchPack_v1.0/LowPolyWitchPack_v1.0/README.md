# Low Poly Witch & Haunted Forest Pack (Free)
by reodesuxz

28 low poly witch cottage and haunted forest assets: buildings, dead trees, cauldron, potions, graveyard props and more.

## Contents
- FBX/  - one .fbx per model (Unity, Unreal, Godot, Blender)
- GLB/  - one .glb per model (Godot, three.js, Babylon.js, web)
- OBJ/  - one .obj + .mtl per model
- Witch_AllAssets.blend - every model in one Blender file (Blender 4.3+)

## Specs
- Total: 2924 triangles for all 27 models (36-248 tris each)
- Flat-shaded, simple shared materials (no textures needed)
- Real-world scale in metres, pivot at the base centre
